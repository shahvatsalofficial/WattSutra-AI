What it does not do

  • No power sensor is read. No kWh or CO2e is measured.
  • One built-in workload; it is not a representative AI inference benchmark.
  • A hash detects edits. It is not a signature and cannot stop a complete forgery.
  • Skills are copied into IDE folders; activation in each IDE is not verified.
FAQ

Quick answers

More in the FAQ and glossary.

Does it measure watts?

No. Version 0.2.1 reads no power sensor. You can import your own meter reading, and it is labelled as imported.

Can it benchmark my app?

Not yet. It ships one fixed workload with two algorithms. Arbitrary code needs a sandbox, which is on the roadmap.

Does it need an API key or network?

No key, no telemetry, no network client. npx downloads the package from npm.

Is the audit a certificate?

No. It is a self-audit you can rerun, not third-party certification.
