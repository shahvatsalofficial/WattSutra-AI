# Roadmap

- **P0 — Working offline foundation:** built-in benchmark, evidence schema, quality parity, compare, explicit-input estimate, CLI, reports, tests and secure skill copying. Implemented in starter.
- **P1 — Instrumentation:** optional approved meter readers (RAPL, NVML and sensor-specific backends), explicit measurement boundaries, scope metadata and calibration checks.
- **P2 — Reproducible experiment framework:** randomization, cold/warm separation, resource isolation, confidence intervals and quality gates; low-overhead validated runner.
- **P3 — Framework integrations:** OpenTelemetry, k6, Kepler, CodeCarbon, Scaphandre, Impact Framework, Ollama and optional provider-billing imports. Each individually permissions-scoped.
- **P4 — Cross-IDE release:** real invocation tests for Claude Code/Cursor/Codex/Gemini/Copilot and agent wrappers; all supported OS CI.
- **P5 — Secure server/dashboard:** RBAC, tenant isolation, audit trail, data retention, secrets management and accessible reporting UI.
- **P6 — Public beta:** docs, examples, SOC2-independent threat model and community governance, versioned npm artifact and verified registry identity.
