# Contributing

Thank you for improving WattSutra AI. Start with `npm test`, `npm run demo`, and `docs/STATUS.md`. File issues with minimal reproducible fixtures and no secrets. Submit focused changes accompanied by tests, provenance annotations and cross-platform considerations. Do not claim measured energy without direct sensor provenance and defined attribution; do not silently enable network traffic. Maintain Apache-2.0 copyright notices where applicable and credit contributors.
