# Agent execution contract

Canonical specialist roles are in `agents/manifest.json`; their portable SKILL.md files are in `skills/wattsutra-*/SKILL.md`. WattSutra Prime coordinates a privacy guardian, a benchmark-methodology review and an evidence-quality gate. Assign tasks to independent roles only where the host supports them. All agents are read-only unless a user authorizes a bounded operation. Each produces evidence, observed/inferred/unknown classification, and an action plan. Skills alone do not create independent running AI models.
